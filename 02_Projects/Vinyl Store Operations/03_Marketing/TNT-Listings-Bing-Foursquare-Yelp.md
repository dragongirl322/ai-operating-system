## 4. Per-platform playbooks

### A. Bing Places for Business (do first)

- **Claim URL:** https://www.bing.com/forbusiness (new home since Oct 3, 2025; old www.bingplaces.com redirects here)
- **Support (if stuck):** https://www.bing.com/forbusiness/contactSupport
- **Login needed:** a **Microsoft account**. Recommend creating/using one on **tnt@tntmusic.shop** so the business owns it. Microsoft sends a sign-up code to that inbox, and Groove cannot read tnt@ (Gmail not connected), so **Tam has to read the code** or do the sign-in once on Groove's box browser.
- **Fastest path: Import from Google Business Profile.**
  1. Sign in at bing.com/forbusiness with the Microsoft account.
  2. Search "TNT Music, Edmonds WA". If a Bing listing already exists, **Claim business** it; otherwise use **Import from Google Business Profile**.
  3. Click Import from Google, sign in with **the Google account that manages TNT's GBP**, click **Allow**.
  4. Turn on **automatic sync** (GBP changes flow to Bing, so Groove keeps editing only GBP).
  5. Select TNT Music and import.
- **Verification:** if GBP is verified (it is) and the address imports cleanly, Bing usually **auto-verifies**. If not, Bing offers a 6-digit PIN by **phone, text, email, or postcard** (US postcards take about 5 to 6 business days; wait 12 days before contacting support). The PIN has to be entered **in the same Microsoft account** that started verification.
- **After import, check/fill:** category (Bing often needs it picked by hand: Record Store, then Music Store), hours, website, phone, description (long version), social links (Instagram, Facebook), photos (cover IMG_0106 + logo + 4 more), women-owned if offered. Publishing changes can take up to about 10 days.
- **Watch out:** with sync on, conflicting edits made in Bing are overwritten by GBP. Make fixes in GBP.

| Microsoft account exists on tnt@tntmusic.shop (or Tam picks another) | Need Tam | Tam |
| Sign in on Groove's box browser (one time) | Need Tam | Tam (or Tam reads the code to Groove) |

- **After verifying:** submit sitemap https://tntmusic.shop/sitemap.xml, run URL Inspection on the homepage and /pages/contact, request indexing.
