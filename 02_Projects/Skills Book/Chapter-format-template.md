# Chapter Template

**Book:** Before It Was Urgent — Nine Skills Design and Research Leaders Should Have Been Building All Along

For consistency across all nine skills chapters, so a reader who finishes chapter one already knows how to navigate chapter nine.

1. **Open** — a concrete scene or question, not an abstract claim.
2. **Reframe** — this skill mattered before AI. Name plainly what AI changed: it didn't create the need, it removed the excuse to skip it.
3. **The core model** — one primary, ownable idea the reader leaves with. The thing they repeat to someone else next week.
4. **Where it comes from** — enough grounding in outside expertise to earn credibility. Not a survey.
5. **In practice** — one or two exercises the reader can run this week, without a facilitator.
6. **Close** — return to the opening scene. Bridge to the next chapter.
